PowerShell is Microsoft's command-line shell and scripting language designed for system administration and automation. It allows administrators to manage Windows, Active Directory, IIS, services, processes, networking, and many other components using commands and scripts. Unlike Command Prompt, PowerShell is object-oriented, meaning it works with .NET objects instead of plain text. It supports cmdlets, scripting, pipelines, remote administration, modules, and automation, making it an essential tool for managing Windows servers and enterprise environments efficiently.





***# What is the extension of a PowerShell script?***

.ps1



***# What is the difference between CMD and PowerShell?***

CMD is a basic command interpreter that primarily works with text output, whereas PowerShell is an object-oriented shell with advanced scripting, automation, and remote management capabilities.



***# What is a cmdlet?***

A cmdlet is a lightweight PowerShell command that follows the Verb-Noun naming convention, such as Get-Service or New-Item.
